# 三角洲口琴简谱 v1
# 手机界面音键：1 2 3 4 5 6 7 1'（1' = 同排高音 do，谱面也可写 #1，播放时会打 1'）
title: 示例音阶
bpm: 96

# 语法速查:
# 1-7 音高；1' 同排高音 1（第 8 键）
# s1 半音(+1) #2 升调(+八度，2–7) b1 降调(-八度)
# ##1 = 再高八度（升调 + 1'）
# /4 /8 /16 /2 时值（默认 /4）
# 0/4 休止；| 小节线；> 歌词
# 连音线：同音用 + 合并时值（5/16+5/8）；异音圆滑可 5/8+6/8 或紧挨着写
